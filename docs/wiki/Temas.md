# Temas

> [English version](Themes)

El tema se elige en Ajustes (rueda) → **TEMA** (también en el tutorial de la primera
ejecución). Hay tres modos:

- **Oscuro**: fondo negro OLED puro (`#070809`), superficie `#111315`, bordes
  `#26292e`. Pensado para pantallas OLED y para que de noche no deslumbre.
- **Claro**: grises industriales mate (`#d8dbe0` de fondo, `#cbcfd5` de
  superficie, texto `#111418`). Nunca blanco puro, para no cansar la vista.
- **Sistema**: sigue al modo claro/oscuro de Windows.

## Acento

Diez colores rápidos incluidos, más un color libre con el selector. El acento
se aplica a toda la app (bordes, insignias, preselección) y se guarda con el
perfil al exportarlo.

Todo el color de la interfaz sale del tema activo: cambias una vez y todas las
pantallas —principal, editor, ajustes, kiosko, barra flotante y mando móvil—
se actualizan.
