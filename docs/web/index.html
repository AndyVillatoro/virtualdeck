VIRTUALDECK

Un Stream Deck en la pantalla que ya tiene. Botones táctiles para lanzar programas, controlar la música, el audio, las luces RGB y las macros — sin comprar hardware.

DESCARGAR PARA WINDOWS CÓDIGO FUENTE

Gratis y de código abierto · Windows 10 y 11

QUÉ HACE

Lanza lo que sea

Programas, páginas, carpetas, scripts de PowerShell o CMD, atajos de teclado y macros grabadas.

Controla el sonido

Cambia el dispositivo de salida, fija el volumen a un porcentaje exacto, o lo sube y baja desde donde esté.

Lo que suena

Carátula, título y controles reales del reproductor — no teclas multimedia a ciegas.

Luces RGB

Por OpenRGB: color, modo y 18 ambientes prehechos, con calibrador de zonas y pintado LED a LED.

Sensores en pantalla

Temperatura, carga y consumo. Un botón puede dispararse solo al cruzar un umbral.

Widgets

Reloj, clima, divisas, sensores y variables propias, dentro de la propia casilla.

Y ALGUNAS QUE NO ESPERA

  • Modo kioskoA pantalla completa, sin barra y con PIN para salir. Para una tableta vieja colgada en la pared.
  • Mando desde el móvilEl teléfono abre una página servida por el propio deck. Se empareja con un código de seis cifras que caduca a los cinco minutos.
  • Un deck manda sobre otroEl portátil pulsa botones del equipo de sobremesa por la red local.
  • Disparadores externosEnlaces virtualdeck:// y una API HTTP con token: desde un .bat, el Programador de tareas o Home Assistant.
  • Galería de perfilesDecks completos hechos por otros — y antes de importar se le enseña todo lo que ese perfil ejecutará y teclará en su equipo.
  • Español e inglésIncluidos el menú de la bandeja y los mensajes de error, que es donde suelen quedarse a medias.

MANDARLE DESDE FUERA

:: desde un .bat, un acceso directo o el Programador de tareas
start virtualdeck://press/Spotify
start virtualdeck://page/2

:: o por HTTP, con el token de sus ajustes
curl -H "X-VD-Token: SU_TOKEN" http://192.168.1.50:8787/api/press/Spotify
